# 混合终端个人博客 Spec

## Why
北理工自动化大二学生需要一个既能正常浏览、又带「真实终端」彩蛋入口的个人博客，用于记录学习分享、工作进展与生活随想。目标：酷而不刺眼、视觉舒适、终端可自由探索。

## What Changes
- 新建 React + Vite 项目（纯 CSS，无外部 UI 库）。
- 主内容区：图形化博客界面（顶栏导航 + 日志 / 项目 / 关于三模块，无刷新切换）。
- 终端区：底部固定终端栏（PC 约 200~280px），支持真实命令交互、上下键历史、自动聚焦、类型打字机输出。
- 终端与主内容联动：`projects` / `blog` / `contact` 等命令会切换主内容区模块。
- 彩蛋：表白关键词触发全屏彩带动画；`生日`、`星空`、`sudo`、`matrix` 等趣味命令。
- 版心：PC 端主内容最大宽度约 1700px（用户最终明确要求），居中。

## Impact
- 影响代码：全新项目，无历史代码。
- 数据：全部使用虚拟占位内容（示例文章、示例项目、示例个人简介）。

## ADDED Requirements

### Requirement: 项目脚手架
系统 SHALL 提供可运行的 React + Vite 项目，包含 `npm run dev` 启动脚本、`npm run build` 构建脚本。

#### Scenario: 启动开发服务器
- **WHEN** 用户执行 `npm run dev`
- **THEN** 本地服务器启动，浏览器打开后可看到混合终端博客页面

### Requirement: 主内容区（图形化博客）
系统 SHALL 渲染图形化主内容区，包含：
- 固定顶栏：网站名（`~/blog`）、导航标签（日志 / 项目 / 关于）、当前时间（实时刷新）。
- 「日志」：文章列表（标题 + 日期），点击标题展开全文；文章行数与日期间距适中。
- 「项目」：卡片网格（图片占位、名称、简述），点击展开详情。
- 「关于」：头像占位、个人介绍（北理工自动化、机器人 / 运动控制 / 具身智能方向）、联系方式、项目数据、学习方向、博客初衷。
- 鼠标悬停有轻微反馈（上浮、边框高亮），点击切换平滑淡入、无页面刷新。

#### Scenario: 导航切换
- **WHEN** 用户点击顶栏「日志 / 项目 / 关于」
- **THEN** 内容区淡入切换至对应模块，URL 不刷新

#### Scenario: 展开文章
- **WHEN** 用户点击某篇文章标题
- **THEN** 该文章全文展开（可再次点击收起），其余文章状态不受影响

### Requirement: 终端区
系统 SHALL 在页面底部渲染固定终端栏（PC 高度约 200~280px，窄屏适配见响应式要求），包含经典红黄绿装饰点与略深于主背景的底色（#0F1113）。

终端 SHALL 支持：
- 必须命令：`help`、`clear`、`about`、`projects`、`blog`、`contact`、`email`、`github`、`cd`、`ls`、`ps`、`cat`、`nano`。
- 创意命令：`date`、`whoami`、`uptime`、`echo`、`sudo`（权限梗）、`dark` / `light`（主题切换）、`fortune`、`cowsay`、`matrix`、`生日`、`星空` 等。
- 上下键浏览历史命令；页面加载后输入框自动聚焦，点击终端区域自动聚焦。
- 错误命令输出友好提示（如 `command not found: xxx`，附带 `help` 提示），不崩溃。
- 输出支持纯文本、简单表格、彩色文字；打字机效果仅终端输出使用（速度适中）。

#### Scenario: 输入帮助命令
- **WHEN** 用户在终端输入 `help`
- **THEN** 终端输出全部可用命令清单（可带颜色与简单排版）

#### Scenario: 输入错误命令
- **WHEN** 用户在终端输入不存在的命令
- **THEN** 终端输出友好错误提示且程序不崩溃

#### Scenario: 浏览命令历史
- **WHEN** 用户按键盘 ↑ / ↓
- **THEN** 终端输入框依次回显历史命令

### Requirement: 终端与主内容联动
系统 SHALL 在终端执行 `projects`、`blog`、`contact` 等导航类命令时，除终端自身输出信息外，同时将主内容区切换到对应模块；`help`、`date` 等非导航命令仅终端内响应，不联动。

#### Scenario: 终端输入 blog
- **WHEN** 用户在终端输入 `blog`
- **THEN** 终端输出文章摘要列表，主内容区自动切换到「日志」模块

#### Scenario: 终端输入 date
- **WHEN** 用户在终端输入 `date`
- **THEN** 终端输出当前时间，主内容区不发生变化

### Requirement: 彩蛋系统
系统 SHALL 实现以下彩蛋：
- 表白触发：终端输入包含「喜欢」或「爱」等表白字眼（如「我喜欢你」「我爱你」）时，屏幕左右两侧同时炸开五彩纸屑 / 彩带动画，持续几秒后自动消失。
- `生日`：显示生日祝福动画（如蛋糕 / 祝福语）。
- `星空`：切换背景为星空效果。
- `sudo`：显示「你并没有管理员权限 😜」。
- 鼓励额外隐藏彩蛋，但不得影响正常使用。

#### Scenario: 输入表白语句
- **WHEN** 用户在终端输入「我喜欢你」
- **THEN** 屏幕左右两侧同时出现五彩纸屑 / 彩带，几秒后自动消失

### Requirement: 视觉风格
- 背景暖调深灰 #1A1C1E（非纯黑），文字柔和白 #E4E4E7，点缀色 #D4A373（暖黄）与 #8BB3A0（青绿）。
- 终端使用等宽字体（JetBrains Mono，可引入 web 字体，缺失时回退系统等宽），主内容用系统无衬线 / 等宽，正文字号 ≥16px、行距 ≥1.8。
- 终端窗口略深（#0F1113），带红黄绿装饰点，边框细亮。
- 动画：终端输出打字机、主内容切换淡入。

### Requirement: 响应式布局
- PC 宽屏：底部固定终端栏（方案 A），版心约 1700px。
- 手机 / 窄屏：终端区收缩为可展开/收起的面板或占屏底部条，保证主内容滚动流畅、终端仍可操作（如固定窄条 + 点击展开）。

#### Scenario: 窄屏浏览
- **WHEN** 用户在窄屏（手机宽度）打开页面
- **THEN** 终端以紧凑形式呈现（可收起），主内容区仍可流畅滚动

## MODIFIED Requirements
无（全新项目）。

## REMOVED Requirements
无。
