# Checklist

- [x] 项目可通过 `npm run dev` 启动并在浏览器正常显示
- [x] 顶栏包含网站名 `~/blog`、日志 / 项目 / 关于导航标签、实时时间
- [x] 日志模块：文章列表（标题 + 日期），点击标题可展开 / 收起全文
- [x] 项目模块：卡片网格（图片占位、名称、简述），点击可展开详情
- [x] 关于模块：头像、个人介绍、联系方式、项目数据、学习方向、博客初衷齐全
- [x] 模块切换为淡入、无刷新；悬停有上浮 / 边框高亮反馈
- [x] 底部固定终端栏：红黄绿装饰点、底色 #0F1113、细亮边框
- [x] 必须命令 `help / clear / about / projects / blog / contact / email / github / cd / ls / ps / cat / nano` 均可执行
- [x] 创意命令（date / whoami / uptime / echo / sudo / dark / light / fortune / cowsay / matrix / 生日 / 星空 等）可执行
- [x] 上下键可浏览历史命令；页面加载与点击终端均自动聚焦
- [x] 错误命令输出友好提示，不崩溃

- [x] `生日` 触发生日祝福动画；`星空` 切换星空背景；`sudo` 显示权限梗
- [x] PC 端版心约 1700px 居中；窄屏终端可展开 / 收起，主内容滚动流畅
